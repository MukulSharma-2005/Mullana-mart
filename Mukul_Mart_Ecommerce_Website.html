Mukul Mart is a front-end e-commerce demonstration created to showcase web page structure, responsive styling, DOM manipulation, event handling, search, filtering and cart calculations using HTML, CSS and JavaScript.

This project uses sample products and prices. It does not process real payments or save orders to a server.
